# CRM Analytics Dashboard — Olist Brazilian E-Commerce

**Nama:** Aulia Rahma Bidayah  
**NIM:** L0224003

Dashboard ini menganalisis data e-commerce Olist untuk melihat perilaku pelanggan, nilai transaksi, dan retensi. Dashboard terdiri dari tiga bagian:

1. **Ringkasan & Asal Pelanggan** — KPI utama, tren revenue, peta sebaran pelanggan, top 10 kota, dan revenue per state.
2. **Pelanggan Terbaik & Nilai Transaksi** — pelanggan teratas, kurva Pareto, distribusi nilai transaksi, segmen RFM, kategori produk, metode pembayaran, dan jumlah cicilan.
3. **Churn, Loyalitas & Strategi** — segmen pelanggan, distribusi recency, pelanggan berisiko, cohort retention, kepuasan vs keterlambatan pengiriman, dan matriks strategi pemasaran.

Dashboard dibuat dengan **Streamlit + Plotly** dan dilengkapi filter tanggal, state, kategori produk, serta segmen RFM.
